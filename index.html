Service Breakdown

🌐
Amazon Route 53
The domain anujdhirde.in has its name servers pointed to Route 53. A Public Hosted Zone is configured with NS and SOA records auto-created by AWS. An A record (Alias) maps the domain to the Application Load Balancer's DNS name, enabling seamless traffic routing.
DNS & Domain
⚖️
Application Load Balancer
The ALB sits in front of the EC2 instance, handling incoming HTTP (port 80) and HTTPS (port 443) traffic. Listener rules forward all requests to a target group containing the EC2 instance. The ALB also provides health checks and can scale to multiple instances in the future.
Load Balancing
🖥️
Amazon EC2
An EC2 instance (Amazon Linux 2 / Ubuntu) runs the web server (Nginx or Apache). The HTML portfolio file is served directly from the instance. It lives inside a VPC with a Security Group allowing inbound port 80/443 from the ALB only — not exposed directly to the internet.
Compute
🪣
Amazon S3
Static assets such as the Resume PDF are stored in an S3 bucket. The EC2 server references S3 for file delivery. Bucket policies control public read access for specific objects, while sensitive files remain private until authenticated access is granted.
Object Storage

Request Walkthrough — Step by Step

1
🌍 User Types anujdhirde.in
The browser initiates a DNS lookup. The domain's registrar NS records are delegated to Amazon Route 53's name servers (ns-xxx.awsdns-xx.com), so the query is routed to AWS.
2
🌐 Route 53 Resolves the Domain
Route 53's Public Hosted Zone for anujdhirde.in responds with the ALB's DNS name via an Alias A record. This returns the ALB's IP addresses to the browser.
A ALIAS → my-alb-123456789.ap-south-1.elb.amazonaws.com
3
⚖️ ALB Receives the HTTP/HTTPS Request
The Application Load Balancer's listener on port 80/443 receives the request. The listener rule matches all traffic and forwards it to the registered target group containing the EC2 instance. SSL termination happens at the ALB level using ACM (AWS Certificate Manager).
4
🖥️ EC2 Serves the Portfolio
The EC2 instance in a private/public subnet runs a web server (Nginx). The HTML portfolio file is served in response. The Security Group allows inbound traffic only from the ALB's security group, keeping the EC2 protected from direct internet access.
nginx → /var/www/html/index.html → Response 200 OK
5
🪣 S3 Serves Static Assets
When the resume or other static files are requested, the EC2 server references objects stored in S3. The resume PDF is stored securely and served to authenticated users only — unauthenticated users can preview via the in-page PDF viewer but cannot download.
s3://anujdhirde-portfolio/resume/Anuj_Dhirde_Resume.pdf
🏗️ Architecture Summary

This setup demonstrates a real-world, production-grade AWS deployment — using Route 53 for DNS, an ALB for scalable and secure traffic routing, EC2 for compute, and S3 for durable object storage. It mirrors architectures used by enterprise applications and aligns with the AWS Solutions Architect Associate exam topics Anuj is currently studying.
