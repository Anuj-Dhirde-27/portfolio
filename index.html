EventHub — Serverless Event Platform

AWS · Serverless · 2026

A fully serverless platform where users browse events, subscribe for email alerts, and post new events through an API-driven workflow — with no servers to manage.

  • Two independent Python Lambda functions behind API Gateway REST endpoints (POST/GET).
  • S3 hosts the static frontend and stores event data; SNS sends subscriber email notifications.
  • Least-privilege IAM roles and CORS secure every browser-to-service call.
  • CloudWatch logs used for end-to-end troubleshooting; documented with a diagram and demo video.
